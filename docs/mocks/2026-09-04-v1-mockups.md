# Morning Fit — v1 design mocks

Personal morning routine app: a few minutes of strength, a few minutes of stretching.
Installed on iPhone as a home-screen web app (PWA). One user, one device, no accounts.

Two top-level views, switched by a bottom tab bar: **Plan** and **Train**.

## Rendered mocks

- Plan screens: [screens/_plan_screens.png](screens/_plan_screens.png)
- Train screens: [screens/_train_screens.png](screens/_train_screens.png)
- All exercise figures, relaxed and flexed: [figures/_all_figures.png](figures/_all_figures.png)
- Individual screens: `screens/*.png` (390×844 pt iPhone frame, rendered at 2x)
- Individual figures: `figures/<exercise>_<relaxed|flexed>.svg` and `.png`

Everything is generated from `tools/figures.py` (poses as joint coordinates)
and `tools/render_screens.py`. The figure SVGs are the ones the app will ship.

---

## Decisions so far

1. Every step is timed in seconds. No reps.
2. **Every exercise carries its own default time and default rest**, defined with
   the exercise in code. Nothing is global. The initial values are 60s for regular
   exercises and 90s for sided ones, but any exercise can be given a different value.
   - Sided = left then right. Time is the total; each side gets half, with a
     "switch sides" cue at the midpoint.
   - Per-step time and rest are set in the Plan view and override the defaults
     for that workout only.
3. The exercise bank is defined in code. Each exercise ships with two figures
   (relaxed and flexed) drawn as flat SVG line art, one pair per exercise.
   Adding or changing an exercise = editing the code. No in-app editor, no uploads.
4. Session screen is **stacked**: relaxed figure, timer, flexed figure.
5. Steps auto-advance when the timer hits zero, with a beep and a vibration.
6. **Rest belongs to the exercise, not a separate step.** Every exercise in the bank
   has a default rest (e.g. 20s after strength, 5–10s after stretches). Each step
   in a workout carries its own rest value, editable in the Plan view, shown greyed
   next to the exercise time. Rest of 0 means go straight on. **The last step's rest
   is never run**, even if it is set: the session ends when the last exercise ends,
   and totals exclude it. It stays stored so reordering the step keeps its rest.
7. Data lives on the phone. Backup/restore via a JSON file.
8. No history or stats. Portrait only. Dark theme.

## Exercise definitions (in code)

Each exercise is one entry in a list plus two SVG files. Adding one means
adding an entry and drawing two figures. Starting bank, to be trimmed or
extended before build:

| Exercise           | Type     | Sided | Time | Rest | Relaxed figure          | Flexed figure              |
|--------------------|----------|-------|------|------|-------------------------|----------------------------|
| Push-ups           | strength | no    | 60s  | 20s  | top of push-up (plank)  | chest near floor           |
| Jackknife sit-ups  | strength | no    | 60s  | 20s  | lying flat, arms overhead | V-sit, hands reaching feet |
| Cat / cow          | stretch  | no    | 60s  | 10s  | cow (back dipped)       | cat (back arched)          |
| Cobra              | stretch  | no    | 60s  | 10s  | lying face down         | chest lifted on straight arms |

These four are the whole bank for v1. None of them is sided, but sided support
(left/right halves with a midpoint cue) stays in the design so a sided exercise
can be added later by setting one flag.

Figures: flat, single colour, same stroke weight and proportions across the
whole set so the session screen looks consistent. Relaxed drawn muted, flexed
in the type colour.

## T2 — Session (the core screen), stacked layout

```
┌──────────────────────────────┐
│  ✕            Morning A  3/4 │   ← exit (confirm), workout, exercise index
│  ████████████████░░░░░░░░░░░ │   ← overall progress bar
├──────────────────────────────┤
│  CAT / COW                   │   ← big, all caps
│  Stretch                     │   ← type · side (side shown for sided only)
│                              │
│  ┌──────────────────────────┐│
│  │                          ││
│  │       relaxed (fig)      ││   ← full width, ~22% of screen height
│  │                          ││
│  └──────────────────────────┘│
│                              │
│            0:38              │   ← huge countdown, tabular digits
│     ▐█████████░░░░░░░░▌      │   ← this-step bar draining
│                              │
│  ┌──────────────────────────┐│
│  │                          ││
│  │       flexed (fig)       ││   ← full width, ~22% of screen height
│  │                          ││
│  └──────────────────────────┘│   (no labels; relaxed is muted, flexed
│                              │    is coloured, that is enough)
│  Move with the breath        │   ← cue, small, muted
│  Next: Cobra 60s (after 10s rest) │
│                              │
│   ‹‹        ▐▐ Pause     ››  │   ← prev / pause-resume / skip
└──────────────────────────────┘
```

Behaviour:
- Timer counts down. At 0 → beep + vibration, auto-advance to the next step.
- Short ticks at 3-2-1 before every transition, including the side switch.
- **Sided steps**: the countdown shows time remaining for the current side
  (45 → 0, then 45 → 0 again). At the midpoint: a distinct double-beep,
  the header flips "Left side" → "Right side", and the figures flash once.
  Nothing to tap; keep going.
- Tap anywhere on the figures/timer area = pause/resume. Paused state dims
  the screen and shows a large "Paused · tap to resume".
- `‹‹` restarts the current step; `‹‹` again within 2s goes to the previous step.
  `››` skips to the next step. On a sided step `››` skips to the other side first.
- Screen stays awake for the whole session (Wake Lock).
- Exit ✕ asks "End session?" only if more than one step remains.

Rest phase (shown after an exercise whose rest is above 0, not counted as a step):

```
│  REST                        │
│  20s · after Push-ups        │
│                              │
│            0:14              │   ← timer, larger, centred vertically
│     ▐████████░░░░░░░░░░▌      │
│                              │
│  Next: Jackknife sit-ups 60s │
│  ┌──────────────────────────┐│
│  │     next flexed (fig)    ││   ← preview of what is coming
│  └──────────────────────────┘│
```

- Skip `››` during rest jumps straight to the next exercise.
- The "Next:" line on an exercise screen names the next exercise and, if there is
  rest first, says so: "Next: Jackknife sit-ups 60s (after 20s rest)".

## Visual style

- Dark background, one accent colour (warm orange) for the timer and primary buttons.
- Strength = accent orange, Stretch = calm teal. Used on chips, thumbnails and the
  session header so the phase is obvious at a glance.
- Figures: single-colour flat line-art on a slightly lighter rounded card.
  Relaxed figure drawn muted; flexed figure in the type colour.
- System font, timer in tabular numerals so digits do not jitter.
- Primary actions at the bottom, reachable with a thumb.

## Data model (informal, for reference)

```
Exercise  { id, name, type: "strength"|"stretch", sided: bool,
            defaultSeconds, defaultRestSeconds,
            relaxedSvg, flexedSvg, cue }                         ← in code, not stored
Workout   { id, name, steps: [ {exerciseId, seconds, restSeconds} ] }   ← stored on phone
```

Only workouts are stored on the phone. Backup = one JSON file of workouts.
If an exercise is removed from the code, steps that reference it show as
"missing" in the editor and are skipped in a session.
