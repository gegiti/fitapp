Morning Fit (`/root/fitapp`) is a personal, single-user web app the user installs on their iPhone from the Home Screen. v1 was designed via mocks, spec and plan, then built and merged to `main` on 2026-09-04. It is hosted on GitHub Pages at https://gegiti.github.io/fitapp/ from the public repo github.com/gegiti/fitapp (branch `main`, root folder). The user first asked for a private repo, then chose public so free-plan Pages would work. Pushing to `main` redeploys; bump `VERSION` in `sw.js` so installed phones pick up changes.

**Why:** The user wants the app to start minimal and add features only when they need them. Decisions that are not obvious from the code:
- The exercise bank is intentionally code-only (no in-app editor, no uploads). Adding an exercise means a pose in `tools/figures.py` plus an entry in `js/exercises.js`. The user chose this over a gallery.
- Figures are flat line-art SVGs generated by Claude from joint coordinates; the user was happy with the style ("looks amazing") and does not want text labels under the figures on the training screen.
- Rest belongs to each step with per-exercise defaults; the last step's rest is never run. Exercise time defaults are per exercise (60s regular, 90s sided). The bank grew to 12 on 2026-09-05 and 14 on 2026-09-08: push-ups, jackknife sit-ups, sit-ups, prisoner squeeze, bird dog, superman, cat/cow, cobra, cow child, squat to fold, dog to lunge rotation, seated side stretch (the only sided one; bird dog and dog to lunge were un-sided on 2026-09-06 because the user alternates sides within reps, now 60s like other regular exercises), 90-90 (front-view windshield-wiper knee drop, alternating so not sided, 60s), kneeling hip flexor (sided, 90s; reused the HIP_FLEX_* poses that had been sitting unused in figures.py). The seed workout still holds the original four. Titles 'Squat to fold', 'Dog to lunge rotation' and 'Seated side stretch' were placeholders the user did not rename.
- The user cares about data durability on iOS (asked explicitly). Mitigations chosen: seed workout in code, dual localStorage+IndexedDB, file backup/restore, visible notice when defaults are loaded.

**How to apply:** The user's workflow for new exercises: they describe the movement, I draw the pair with `tools/preview.py <name> <RELAXED> <FLEXED> <type>` and embed the PNG, iterate on the pose until they approve, and only add it to the bank when they say implement. Keep changes small and only on request. When adding exercises, follow the README recipe and bump `VERSION` in `sw.js`. Next likely step: the user installs it on the real phone and reports back (sound after Start, wake lock, backup to Files are unverified on device).
